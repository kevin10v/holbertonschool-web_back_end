## Description

This repository covers **server-side web development** using Python and Node.js. Topics include REST APIs, authentication, databases (SQL & NoSQL), caching, pagination, and background jobs.

## Projects

| Directory | Topic |
|-----------|-------|
| `python_variable_annotations` | Type annotations in Python |
| `python_async_function` | Asyncio and coroutines |
| `python_async_comprehension` | Async generators and comprehensions |
| `caching` | Cache replacement policies (FIFO, LIFO, LRU, MRU, LFU) |
| `pagination` | Paginating datasets with hypermedia metadata |
| `i18n` | Internationalization with Flask-Babel |
| `queuing_system_in_js` | Redis queuing with Kue (Node.js) |
| `Session_authentication` | Session-based authentication |
| `Basic_authentication` | HTTP Basic Authentication |
| `user_authentication_service` | Full user auth service with Flask & SQLAlchemy |
| `personal_data` | PII filtering, bcrypt, logging |
| `ES6_*` | Modern JavaScript (ES6+) |
| `0x04-TypeScript` | TypeScript fundamentals |

## Learning Objectives

- Build REST APIs with Flask and Node.js/Express
- Implement authentication (Basic, Session, JWT)
- Work with Redis for caching and queuing
- Use SQLAlchemy ORM for database management
- Apply async programming with Python asyncio
- Write type-safe JavaScript with TypeScript
